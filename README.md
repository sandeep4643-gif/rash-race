# 🏎️ RASH-RACE

### Start your engines. Beat the bots. Own the track!

RASH-RACE is a 2D arcade-style racing game built using HTML, CSS, and JavaScript. Race against AI-controlled opponents, avoid collisions, stay on the track, and fight your way to first place!

## 🎮 About the Game

RASH-RACE is a browser-based racing game designed for both desktop and mobile devices. It features competitive AI opponents, track boundaries, collision detection, countdown sequences, and an immersive racing experience.

## ✨ Features

- 🏎️ 2D racing gameplay
- 🤖 AI-controlled opponents
- 🚦 Countdown before race start
- 💥 Collision detection
- 🛣️ Track boundary detection
- 🏆 First-place victory celebration
- 📱 Mobile-friendly landscape gameplay
- 🎮 Touch controls for mobile devices
- ⌨️ Keyboard controls for desktop

## 🕹️ Controls

**Desktop**
- Arrow keys / configured keyboard controls to steer and accelerate.
- Use the configured brake key to slow down.

**Mobile**
- Rotate your phone horizontally.
- Use on-screen acceleration, braking, and steering controls.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
